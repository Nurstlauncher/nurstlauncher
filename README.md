# Nurst Launcher: сайт для GitHub Pages

Файлы: `index.html` (страница), `NurstLauncher.exe` (скачиваемый лаунчер), `.nojekyll`.

1. Создай репозиторий на GitHub и загрузи в корень все файлы из этой папки.
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/`.

Новая версия лаунчера: замени `NurstLauncher.exe` с тем же именем.
